Phase 10 operator experience: `td2d explain <code>` with a richer error catalogue (detail, hint and a troubleshooting section for every error and warning), `td2d describe <section>` with a version, option schema, example and docs anchor for every registry entry, `td2d history show|prune`, `td2d completion bash|zsh|fish`, and `asset list --ids`. Errors suggest the nearest key or asset id, name missing keys, echo wrong values and list allowed keys; a mistyped `--json` still gets an envelope and `TD2D_JSON=1` makes JSON the default. Results report the scale used, `compare` reports scale changes and diff rows, and `preview` reports where each cell is. Generated references for the CLI and schemas, an example gallery, guides for every topic, and checks on links, snippets and images.
