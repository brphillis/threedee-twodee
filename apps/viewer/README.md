# @td2d/viewer

The read-only web viewer for td2d builds, started by `td2d viewer` and written as a static site by `td2d index`. It shows sheets at exact pixel zoom, plays animations in every direction, lists metadata and validation results, compares generations and previews the model in 3D. It reads `build/` and never generates anything.

Part of [td2d](https://www.npmjs.com/package/@td2d/cli): install `@td2d/cli` and run `td2d viewer --open`.

Requires Node.js 24 or newer. MIT licensed.
